This repository contains the scripts used to calibrate, clean, and process Level 1 data from GC-Net, Greenland’s longest-running AWS network initiated by Dr. Konrad Steffen. The dataset includes quality-controlled time series from 16 long-term stations across the ice sheet.

Level 0 Raw logger data, C-files, satellite transmissions, and metadata.  
Level 1 Cleaned and interpolated time series in NEAD format, available via [GEUS Dataverse](https://doi.org/10.22008/FK2VVXGUT).
