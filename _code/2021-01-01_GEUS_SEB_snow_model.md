Access [Python](https://github.com/GEUS-Glaciology-and-Climate/GEUS-SEB-firn-model){:target="_blank"} or [Matlab](https://github.com/BaptisteVandecrux/SEB_Firn_model){:target="_blank"} code on GitHub.

The GEUS Surface Energy Balance and Snow Model simulates surface melt snow evolution using meteorological data from PROMICE and GC-Net stations. The model includes surface temperature determination via energy budget closure and a multi-layer firn model accounting for temperature, density, grain size, and meltwater processes.

Used in the following studies:
- [Vandecrux et al., 2018](https://doi.org/10.1029/2017JF004597)
- [Vandecrux et al., 2020a](https://doi.org/10.1017/jog.2020.30)
- [Vandecrux et al., 2020b](https://doi.org/10.5194/tc-2019-331)
- [Vandecrux et al., 2021](https://doi.org/10.3389/feart.2021.578978)

See full documentation and example runs in the GitHub repository.
